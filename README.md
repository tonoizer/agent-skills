# Agent Skills

Standalone agent skills for Module Federation.

## Skills

- [`mf`](./skills/mf): one entry point for Module Federation docs, config
  inspection, integration, type checks, shared dependency debugging, runtime
  errors, performance checks, and observability reports.

## Install

```bash
npx skills add module-federation/agent-skills --skill mf -y
```

If the CLI is unavailable, copy the skill directory manually:

```text
https://github.com/module-federation/agent-skills/tree/main/skills/mf
```
